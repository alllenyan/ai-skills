# 证据与质量检查

在最终交付、文档审校、行业数字引用和 ROI 分析时使用。

## 1. 证据分层

文档中的重要判断应能识别来源类型：

| 类型 | 使用规则 |
|---|---|
| 用户确认事实 | 可作为现状依据，必要时注明访谈/材料来源 |
| 客户数据 | 说明时间范围、口径、样本和质量限制 |
| 外部事实 | 使用可靠来源，标注机构、日期、适用范围和口径 |
| 合理假设 | 明确标记为假设，并说明验证方法 |
| 示例 | 明确写“示例/参考”，不冒充客户现状或行业标准 |
| 建议 | 说明适用条件、预期收益、风险和依赖 |

## 2. 行业基准与精确数字

任何精确行业数字至少包含：

- 来源机构或原始材料；
- 发布年份或数据期间；
- 行业、市场、企业规模或客户类型；
- 指标定义、分子分母和样本口径；
- 是否能适用于当前客户。

缺少上述信息时：

1. 不把数字写成行业事实；
2. 改成待验证参考或情景假设；
3. 优先提出客户历史数据回测、基线测量和产能校准方法。

ROI 至少给出关键假设、计算公式、保守/基准/乐观情景和敏感因素。避免“必然提升”“无法反驳”等表述。

## 3. 五类质量门

### 3.1 逻辑完整性

- 目标、问题、根因、方案、指标和路线是否能互相追溯？
- 是否把表象问题误写成根因？
- 是否说明异常、退出、变更、反馈和持续改进？
- 建议之间是否存在定义或流程冲突？

### 3.2 业务域适配

- 是否选择了正确的对象类型和分析方法？
- 是否把线索、商机或服务的做法错误复制到其他模块？
- 状态机、SLA、池、评分、审批是否确有业务需要？
- 是否考虑客户旅程、端到端流程和相邻域边界？

### 3.3 可落地性

- 关键节点是否有输入、输出、角色、规则和例外？
- 数据对象、历史、审计和权限能否支撑业务？
- 系统能力是否与流程规则对应？
- 集成是否明确主责系统、触发和失败处理？
- 路线图是否有依赖、优先级、责任和采用措施？

### 3.4 指标与治理

- KPI 是否区分结果、过程、效率和诊断层？
- 每个核心指标是否有定义、口径、维度、责任和管理动作？
- 是否存在为指标而指标、无决策用途或容易刷数的指标？
- 谁维护定义、处理例外、复盘结果并批准变更？

### 3.5 表达与交付

- 执行摘要是否先给判断、影响和行动？
- 结构是否适合管理层、业务和实施受众？
- 是否把事实、假设、示例和建议分开？
- 表格和图是否真正帮助理解？
- 是否存在大量重复、空泛价值或功能清单？

## 4. 常见反模式

出现以下情况时应主动修正：

- 从产品功能菜单开始，而不是从业务目标和问题开始；
- 用“配置更多字段/阶段”证明方案复杂；
- 所有对象都使用同一套状态机；
- 把 BANT、线索池、固定 SLA 或固定阶段当成普遍标准；
- 机会阶段只有销售动作，没有客户里程碑和证据；
- 把来源、归因、状态、资格、归属或历史混在一个字段；
- 营销向销售单向交接，没有退回原因和质量反馈；
- KPI 数量很多，但没有层级、口径和管理动作；
- 默认认为 CRM 是全部对象的主责系统；
- 使用未标来源的行业数字和过度承诺的 ROI；
- 用“必须”“最佳实践”掩盖适用条件和方案取舍；
- 自动扩写或修改用户的长期手册而未获得明确请求。

## 5. P0/P1/P2 评审标准

| 级别 | 判断标准 | 示例 |
|---|---|---|
| P0 | 会导致错误决策、业务闭环断裂、合规/数据风险或方案无法实施 | 数据主责不清、阶段逻辑冲突、无来源关键基准 |
| P1 | 显著影响管理效果、协同、完整性或可运营性 | 缺少反馈回路、历史留痕、治理责任、路线依赖 |
| P2 | 不改变主要逻辑，但影响表达、复用和可读性 | 章节重复、术语不统一、图表选择不佳 |

## 6. 最终交付检查表

- [ ] 业务范围、受众和决策问题清晰；
- [ ] 执行摘要包含判断、问题、方案、优先级和价值；
- [ ] As-Is 有证据，事实与假设已区分；
- [ ] 根因不是简单写成“没有系统”；
- [ ] To-Be 包含业务路径、责任、输入输出、规则和管控；
- [ ] 方法与业务对象类型匹配；
- [ ] 客户里程碑或客户结果得到体现；
- [ ] 异常、退出、变更、反馈和治理形成闭环；
- [ ] 数据、系统和集成能够承载关键规则；
- [ ] KPI 形成层级并对应管理行动；
- [ ] 精确数字具有来源和适用性说明，或明确标记为假设；
- [ ] 路线图包含优先级、依赖、责任和风险；
- [ ] 没有无追溯关系的功能、字段或指标；
- [ ] 篇幅与受众匹配，没有为了完整而无限扩写；
- [ ] 未经用户明确要求，没有写入或改动外部文档。
